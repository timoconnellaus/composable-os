# Guides

Cross-cutting guides, published on the docs site (`apps/docs`, ADR 0930) under Guides. Each file
starts with front matter giving its `title`, a one-line `description` and its `order` in the
sidebar. Links to other files in the repository work on GitHub and on the site: a link to a guide
or a pack's overview becomes its page, and any other file links to GitHub. A pull request that
changes what a guide describes updates the guide in the same pull request.
