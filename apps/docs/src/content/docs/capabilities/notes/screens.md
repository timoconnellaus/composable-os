Its blocks, for client apps (copied with `cos add`) and the admin.

| Block | Skin | What it shows |
| --- | --- | --- |
| [web-note-composer](/reference/blocks/web-note-composer/) | web | The note composer (stage 56 step 2), for the web: a staff screen writes a note about a Person (and, beside them, a class, a session, a job): it picks a kind, fills the kind's template (or writes the note, for a kind with none) and picks who reads it from the levels the host lists for that kind. |
| [native-note-composer](/reference/blocks/native-note-composer/) | native | The note composer (stage 56 step 2), for the staff app: a coach writes a note about a Person (and, beside them, the class it was in): picks a kind, fills the kind's template (or writes the note, for a kind with none) and picks who reads it from the levels the host lists for that kind. |
