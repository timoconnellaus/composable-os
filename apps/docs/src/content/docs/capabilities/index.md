A capability is platform work any pack composes: core tables, operations and behaviours, with blocks for client apps. Those documented as a unit are listed here; everything else in the core is in the reference.

| Capability | What it is |
| --- | --- |
| [Agreements](/capabilities/agreements/) | Documents a person agrees to or signs (terms, a waiver, health questions, a parent's consent), kept word for word for good, and enforced so nobody pays or books without what is due. |
| [Consent to be contacted](/capabilities/contact/) | One register of a person's contact choices, one suppression list, the one-tap stop, and one check every message to people passes before it leaves, whoever sends it. |
| [Finance](/capabilities/finance/) | The business's figures for the books, by the business's own day. Day summaries, Sales, Tax, Refunds and the payment provider's payouts, a monthly close that keeps a month exactly as it was, and one CSV file per report for its accountant. |
| [Invoices](/capabilities/invoices/) | Quotes, invoices and credit notes with numbers nobody reuses and documents nobody changes. An issued invoice is an order, paid online or recorded by a person, and put right with a credit note. |
| [Client notes](/capabilities/notes/) | Notes staff keep about a person, each with a kind and a level that decides who reads it, written from the kind's template. |
| [Booking system copy](/capabilities/outside/) | The host's read-only copy of a business's booking system, loaded as lists, matched to People by address and never merged. |
| [Screen versions](/capabilities/screen-versions/) | A client's built screens stored in the host as versions that never change once sealed, checked file by file, kept apart per client. |
| [Today](/capabilities/today/) | The day at a glance for one person, in the business's own time zone. The host's numbers (takings, changes waiting, shifts with nobody on them, checklists missed, unread notices) and the numbers installed packs declare, each shown only to someone who could already read it, with the rows behind each. |
