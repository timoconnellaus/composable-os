Settings are typed, edited in Settings → Extensions. A setting that is a person's to change waits for a person when anyone else changes it.

| Setting | Type | Label | Default | Limits | Description |
| --- | --- | --- | --- | --- | --- |
| `country` | `text` | Your country |   |   | Two letters, e.g. AU. New post options post here unless you list other countries. Set it, then give the seeded Standard post option this country and a price, and turn it on. |
