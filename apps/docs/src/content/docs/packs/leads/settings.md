Settings are typed, edited in Settings → Extensions. A setting that is a person's to change waits for a person when anyone else changes it.

| Setting | Type | Label | Default | Limits | Description |
| --- | --- | --- | --- | --- | --- |
| `defaultSource` | `select` | Default source | `"other"` | one of website, referral, event, outbound, partner, import, other | The source a new lead gets when none is given. |
| `openDealAfterConvert` | `boolean` | Open the new deal after converting | `true` |   | After Convert to deal, go straight to the deal. |
