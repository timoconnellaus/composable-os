These docs follow the `main` branch of the repository. A page changes when the code it is
generated from changes on `main`, so it can describe something newer than the latest release.

Releases are published on the repository's
[releases page](https://github.com/timoconnellaus/composable-os/releases), as pre-releases of
`0.1.0` so far. A release carries every pack in the repository at the commit it was built from.
The release that first or last shipped each pack is not recorded per pack, so these pages do not
give it. To see which packs a release carries, read the `packs.json` in its client kit.
